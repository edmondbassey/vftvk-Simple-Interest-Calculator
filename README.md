# Simple interest calculator starter

An early HTML, CSS and JavaScript exercise from IBM Developer Skills Network.

This fork preserves the original practice snapshot. The form is present, but `compute()` only reads the amount; it does not complete the calculation.

**For the runnable calculator and tests, see [the maintained calculator project](https://github.com/edmondbassey/Final).**

## Files

- `index.html` — amount, rate and term inputs.
- `script.js` — the unfinished calculation function.
- `style.css` — the original styling exercise.
